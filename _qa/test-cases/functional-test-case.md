## 2. 导航 / 页面切换模块 (TC-NAV-xxx)

### TC-NAV-001 顶部导航 5 项跳转
- 步骤: 依次点击 [首页 / 功能 / 下载 / 登录 / 娱乐 / 社交 / 关于]
- 预期: URL Hash 正确切换 (#/features, #/download, #/auth, #/playground, #/social, #/about)
- 桌面端 hover 有明显背景色；移动端汉堡菜单展开后触控项 ≥ 44×44 px

### TC-NAV-002 回到顶部按钮
- 步骤: 首页滚动 3 屏后，右下角显示回到顶部按钮；点击
- 预期: 1 秒内平滑滚回至首屏（prefers-reduced-motion 用户直接跳回无动画）

### TC-NAV-003 新手引导 Spotlight（首次访问）
- 步骤: 清空 localStorage.onboarding_done，刷新首页
- 预期: ① 显示欢迎浮层  ② 5 步引导（欢迎、下载、功能、娱乐、社交） ③ 5 步进度条显示正确  ④ ESC/跳过 均写入 onboarding_done=1  ⑤ 再次刷新不再弹出

## 3. 首页 Hero (TC-HOME-001)
- 首屏加载 ≤ 3 秒 (3G Fast 目标)
- Hero 主图有 `fetchpriority=high` + `loading=eager`，不产生 CLS
- "立即领养小白" CTA 按钮: 44×44+ 可点击；tab/enter 可聚焦可触发

## 4. 功能 Features 页 (TC-FEAT-001 ~ TC-FEAT-003)
### TC-FEAT-001 跨分类热度 Top3 正确显示
- 点赞社交 3 个卡片各点一下，刷新后热榜顺序变化

### TC-FEAT-002 卡片跳转
- 每个卡片右下角"去试试" → `/#/playground/xxx` 跳转到对应单页

### TC-FEAT-003 喜欢/点赞分享
- 点爱心 icon 数量 +1；再点一次回退

## 5. 下载页 (TC-DOWN-001 ~ 002)
- TC-DOWN-001 点击下载后计数器 +1；下载按钮防重复点击（1 秒冷却）
- TC-DOWN-002 Windows / macOS / Linux 三平台显示正确安装包大小与 SHA256

## 6. 娱乐 Playground (TC-PG-001 ~ 008)
### TC-PG-001 最高分持久化
- 任一游戏得高分 → 关闭重开 → 最高分仍显示在 HUD
### TC-PG-002 暂停功能 (P / ESC)
- 点击暂停，计时器/AI 停止；画面变暗
### TC-PG-003 操作提示条 (GameHintBar)
- 每款游戏开局显示"↑ ↓ ← → 移动 / 空格射击"等提示，3 秒后淡出
### TC-PG-004 游戏结束浮层 + 浮动分数
- 胜负状态有标题、得分、历史新高皇冠动画；点击再来一局可重开
### TC-PG-005 移动端触控按钮
- 屏幕宽度 < 640px 显示虚拟方向键 A/B，尺寸 48×48 px
