# 小白用户体验测试执行计划
**面向人群**: 5~8 名真实零基础小白用户（父母/长辈 / 小学 5 年级以上 / 第一次使用本产品）
**执行时长**: 每人 45~60 分钟  **产出**: 任务脚本、录屏、眼动热力图、满意度评分、访谈记录

## 招募标准
| 标签 | 样本数 | 描述 |
|---|---|---|
| 组 A: 父母/长辈 (50-70 岁) | 2~3 | 只用微信、不会装软件；几乎零电脑基础 |
| 组 B: 学生 (10-18 岁) | 2~3 | 会用抖音/小游戏，但不会 Git、命令行 |
| 组 C: 普通上班族 25-35 岁 | 1~2 | 会用电脑办公，但不是程序员 |
| 合计 | 5~8 人 | - |

## 任务场景脚本 (小白用户照着念就能做)
### 任务 1：找到桌面宠物下载按钮，把小白安装到 Windows
- 成功标准: 5 分钟内点击到"下载安装包"；完成下载；能说出安装步骤
- 记录指标: 点击次数、搜索路径（是否错误地跑到别的页）、是否需要求助
- 困惑点: （测试后记录）

### 任务 2：注册一个新账号
- 成功标准: 5 分钟内完成；无需询问就能输入正确强度密码
- 记录: 密码修改次数（密码强度条是否减少重试）
- 困惑点: （记录）

### 任务 3：找一款小游戏玩 1 分钟（推荐 2048）
- 成功标准: 自己找到 → 打开 → 拿到 1 个分数
- 记录: 游戏操作流畅度 1~5 分；是否读懂操作提示条
- 困惑点: （记录）

### 任务 4：给最喜欢的一个功能点一个"赞"
- 成功标准: 自己找到 Features 页 → 点爱心或点赞按钮 → 看到数量 +1
- 记录: 是否理解这个功能；会不会分享
- 困惑点: （记录）

### 任务 5：最后用一句话对小白说个评价
- 记录原话（语音转文字）

## 数据采集
1. 录屏 + 摄像头 (用户表情)
2. 眼动热力图（Tobii / WebGazer.js），特别观察首屏视线轨迹
3. 鼠标点击热图 (Hotjar)
4. 任务时间 / 错误次数 / 求助次数 客观量表

## 满意度评分 (SUS 问卷)
每项 1~5 分（1 非常不同意；5 非常同意）：
1. 我觉得我会经常使用这个网站 —— 得分 ___
2. 我觉得这个网站使用起来并不复杂 —— 得分 ___
3. 我觉得网站功能层次清晰 —— 得分 ___
4. 我觉得大多数人很快就能学会使用 —— 得分 ___
5. 我觉得网站的配色和动画很可爱友好 —— 得分 ___
6. 我遇到问题时能快速找到说明或帮助 —— 得分 ___
7. 我愿意把小白推荐给身边朋友 —— 得分 ___
→ **总分 ≥ 4.2 / 5 为目标 (P0)**  本次平均分 ___

## 定性访谈提纲（测试后 10 分钟）
1. "你觉得小白最打动你的地方是什么？"
2. "哪个操作让你最困惑？如果有魔法棒你想怎么改？"
3. "你期望小白以后具备什么新功能？"
4. "用三个词形容这次体验？"
