# 缺陷跟踪管理模板
**编号规则**: `ISSUE-{模块缩写}-{YYYYMMDD}-{序号}`。示例: ISSUE-AUTH-20250315-01

> 把每个缺陷复制一份本模板，填写后存为 `_qa/issues/<编号>.md`

## 缺陷头部信息表
| 字段 | 内容 |
|---|---|
| 缺陷编号 | (填) |
| 标题 | (一句话描述: 在 **X** 环境, **Y** 操作 → 发生 **Z** 现象) |
| 严重性 | ☐ 严重 (崩/挂/数据错/核心功能不可用)  ☐ 高 (核心流程阻塞)  ☐ 中 (影响体验但可绕过)  ☐ 低 (UI/文案/样式小瑕疵) |
| 优先级 | P0 / P1 / P2 / P3 |
| 所属模块 | Auth / Home / Features / Download / Playground-GameXX / Social / Admin |
| 报告人 | 姓名 / 邮箱 |
| 报告时间 | YYYY-MM-DD HH:MM |
| 处理状态 | ☐ 新建  ☐ 已分配  ☐ 修复中  ☐ 待回归  ☐ 回归通过  ☐ 关闭 |
| 解决版本 | 例: v1.2.3-rc.2 (留空直到关闭) |
| 指派给谁 | 开发姓名 / GitHub @ |
